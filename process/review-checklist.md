# Review Checklist

_Used by Ollie for every game before approving for submission._

---

## Gameplay
- [ ] Game loads without errors
- [ ] Core loop functions as described in brief
- [ ] Win/loss conditions work correctly
- [ ] Bonus features trigger correctly (if applicable)
- [ ] RTP is within acceptable range
- [ ] No infinite loops or softlocks
- [ ] Edge cases tested (min/max bet, rapid clicking, etc.)

## Visuals & Audio
- [ ] All assets load correctly (no missing images/sprites)
- [ ] Animations play and complete without glitches
- [ ] UI is readable and clearly laid out
- [ ] Audio plays and loops correctly (if applicable)
- [ ] No visual clipping or z-order issues

## Technical
- [ ] Game meets Stake platform file format requirements (see `resources/stake-requirements.md`)
- [ ] File size is within limits
- [ ] No console errors in browser dev tools
- [ ] Tested on required browsers/devices
- [ ] Build is clean and submission-ready

## Brief Compliance
- [ ] Game matches the brief concept and mechanics
- [ ] Acceptance criteria from brief are all met
- [ ] Any deviations from brief are noted and approved by Tiger
